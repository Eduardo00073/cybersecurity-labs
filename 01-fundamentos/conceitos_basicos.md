# Fundamentos de Segurança da Informação

## Tríade CIA

A base da segurança da informação é composta por três pilares:

### 🔒 Confidencialidade
Garantir que a informação seja acessível apenas por pessoas autorizadas.
- Exemplo: Criptografia de dados, controle de acesso, autenticação

### ✅ Integridade
Garantir que a informação não seja alterada de forma não autorizada.
- Exemplo: Hashing (SHA-256), assinaturas digitais, checksums

### 🌐 Disponibilidade
Garantir que a informação esteja disponível quando necessária.
- Exemplo: Redundância, backups, balanceamento de carga

## Tipos de Ameaças

| Ameaça | Descrição | Exemplo |
|--------|-----------|---------|
| **Malware** | Software malicioso | Vírus, worms, trojans, ransomware |
| **Phishing** | Engenharia social | E-mails falsos imitando bancos |
| **DDoS** | Negação de serviço | Sobrecarga de servidor |
| **Man-in-the-Middle** | Interceptação | Wi-Fi público comprometido |
| **SQL Injection** | Injeção de código | Formulários web vulneráveis |
| **Brute Force** | Força bruta | Tentativa de todas as senhas |

---

## Glossário Essencial

- **Firewall**: Barreira de segurança entre redes
- **IDS/IPS**: Detecção/Prevenção de intrusão
- **VPN**: Rede Virtual Privada (túnel criptografado)
- **Pentest**: Teste de penetração autorizado
- **Zero-Day**: Vulnerabilidade sem patch disponível
- **Honeypot**: Armadilha para atrair atacantes
