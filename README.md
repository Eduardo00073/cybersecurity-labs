## 📖 Sobre o repositório

Repositório educacional de **Segurança da Informação**, abordando conceitos fundamentais, boas práticas e laboratórios defensivos. Todo conteúdo é voltado para **conscientização e proteção**, seguindo princípios éticos do uso responsável da tecnologia.

---

## 🗂️ Estrutura do Repositório

```
.
├── 01-fundamentos/          # Conceitos CIA, tipos de ameaças, glossário
├── 02-redes/                # Modelo OSI/TCP-IP, portas, protocolos
├── 03-hardening/            # Boas práticas de segurança de sistemas
├── 04-criptografia/         # Hash, simétrica, assimétrica, certificados
├── 05-analise-de-trafego/   # Conceitos de análise de pacotes
└── 06-boas-praticas/        # Senhas, 2FA, backup, LGPD
```
