# Politica de Seguranca

Este repositorio (cybersecurity-labs) reune laboratorios praticos de seguranca cibernetica com fins didaticos, mantidos por Eduardo Junior.

## Uso etico

Todo o conteudo deste repositorio e destinado exclusivamente para fins educacionais e testes em ambientes controlados e autorizados. Nao utilize as tecnicas aqui descritas contra sistemas sem autorizacao explicita.

## Reportando um problema

Se encontrar algum problema no material didatico ou identificar uso indevido, abra uma issue explicando o contexto.

## Boas praticas recomendadas

- Execute os laboratorios apenas em ambientes isolados (VMs, redes de teste).
- Nunca utilize as tecnicas em sistemas de terceiros sem permissao.
- Mantenha as ferramentas utilizadas sempre atualizadas.
