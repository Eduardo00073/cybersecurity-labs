# Modelo OSI e TCP/IP

## Modelo OSI (7 Camadas)

| Camada | Nome | Função | Protocolo Exemplo |
|--------|------|--------|-------------------|
| 7 | Aplicação | Interface com o usuário | HTTP, HTTPS, FTP, DNS, SMTP |
| 6 | Apresentação | Formatação e criptografia | SSL/TLS, JPEG, ASCII |
| 5 | Sessão | Gerencia conexões | NetBIOS, RPC |
| 4 | Transporte | Entrega confiável | TCP, UDP |
| 3 | Rede | Endereçamento e roteamento | IP, ICMP, ARP |
| 2 | Enlace | Acesso ao meio físico | Ethernet, Wi-Fi, MAC |
| 1 | Física | Transmissão de bits | Cabos, fibra óptica, rádio |

## Portas Importantes

| Porta | Protocolo | Serviço |
|-------|-----------|---------|
| 20/21 | TCP | FTP (transferência de arquivos) |
| 22 | TCP | SSH (acesso remoto seguro) |
| 23 | TCP | Telnet (acesso remoto inseguro) |
| 25 | TCP | SMTP (envio de e-mail) |
| 53 | TCP/UDP | DNS (resolução de nomes) |
| 80 | TCP | HTTP (web) |
| 443 | TCP | HTTPS (web seguro) |
| 3306 | TCP | MySQL |
| 3389 | TCP | RDP (área de trabalho remota) |
| 5432 | TCP | PostgreSQL |
